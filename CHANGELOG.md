# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-07
### Added
- Cart management with capacity limits (maximum 20 DVDs).
- Formatted cart printing and total cost computation.
- DVD title search functionality.
- Automated unit test suite with unittest.
### Changed
- Refactored code structure into dedicated `aims` package.
